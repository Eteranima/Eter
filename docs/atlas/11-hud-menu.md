# Atlas — HUD de Menu

> **Fundo: VERDE puro (`#00FF00`), sem exceção.**
> **Medidas exatas abaixo — não arredonde, não aproxime.**

Fonte: pasta `src/assets/ui/`.

## Medidas por peça

| Uso | Prefixo de referência | Tamanho (px, EXATO) |
|---|---|---|
| Ícone de aba do menu (grupo/inventário/habilidades/missões/config) | `ui_menu_*` | 44×44 |
| Ícone de tipo de arma (inventário/equipamento) | `icon_<arma>` | 24×24 |
| Cursor de seleção | `ui_cursor` | 28×32 |
| Canto decorativo de painel (moldura) | `ui_canto_01` a `ui_canto_25` | 28×28 |

## Regra para peça NOVA

Ícone de aba de menu: sempre 44×44 exatos. Ícone de item/arma: sempre
24×24 exatos. Um canto de moldura novo (variação de estilo) entra na
mesma sequência numerada, sempre em 28×28 exatos.
